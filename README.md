# Python Insights: Análise de Cancelamento de Clientes (Churn)

Projeto de análise exploratória de dados desenvolvido em Python com o objetivo de identificar os principais fatores que levam ao cancelamento de clientes (*churn*) em uma base de dados contendo aproximadamente 50.000 registros.

O projeto foi desenvolvido como estudo prático durante a **Jornada Python**, evento promovido pela **Hashtag Programação**.

---

## Contexto do Negócio

Uma empresa com uma base total superior a 800 mil clientes identificou um alto índice de inatividade e cancelamento de serviços. 

O objetivo principal desta análise é mapear o comportamento dos clientes cancelados e identificar quais variáveis apresentam maior impacto no *churn*, fornecendo subsídios para estratégias preventivas de retenção.

---

## Objetivos

- Realizar o tratamento e a limpeza da base de dados.
- Conduzir uma Análise Exploratória de Dados (EDA).
- Avaliar o impacto das variáveis operacionais e financeiras sobre a taxa de *churn*.
- Gerar *insights* acionáveis baseados em dados para apoiar a tomada de decisão.

---

## Tecnologias Utilizadas

- **Linguagem:** Python
- **Análise e Manipulação de Dados:** Pandas
- **Visualização de Dados:** Plotly
- **Ambiente de Desenvolvimento:** Jupyter Notebook
